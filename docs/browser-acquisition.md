# 按需网页采集

数据源为 Google Patents 中国专利网页和天眼查企业查询接口。旧离线管道、旧目录及其历史研究已退出运行流程。

## 流程与入库时机

1. 用户创建研究、输入技术方向。此时仅保存研究任务、模型生成的检索计划，不创建采集任务，不写公司或专利事实。
2. 用户确认检索范围后，同一个 `run_id` 创建采集任务。
3. 本机 Python worker 将每个原始中文关键词分别提交给 Google Patents，固定限定 `country=CN`、`language=CHINESE` 和计划年份，串行访问结果页和中文详情页，再按 CN 公开号合并去重并逐条保存详情；多个方向轮流分页，共最多 100 条。排除词和 CPC/IPC 不发送给来源站。
4. 仅保留含中文标题且至少有一家中国企业申请人的中国专利。外国企业、大学、研究机构和纯英文标题不会进入详情采集。优先按当前权利人聚合，缺失时用检索页权利人；确定性选择 Top 20 境内企业型权利人，用户手动开始企业发现。
5. 天眼查返回的有效大陆企业按统一社会信用代码独立入库，保留每个查询命中与供应商顺序，不在采集期关联专利。Agent 解析权利人与候选企业后，系统展开相关专利并生成分级报告；失败时保留专利权利人兜底结果。

空数据库可以从第 1 步开始，不依赖预先生成公司、专利、技术领域或发布目录。目录页面显示最近完成的采集快照；各研究页面展示该研究自己的快照。源事实表跨任务去重保存。

## 本机启动

- `uv sync --project services/research`
- 复制 `services/research/.env.example` 为 `.env`，配置研究与采集数据库连接、内部令牌及模型服务。
- 网页采集是唯一数据来源，不需要来源模式开关。
- `pnpm migrate:research` 初始化 `agent_runtime`、`ingestion` 和 `catalog_v2` schema。
- 给 `CATALOG_DATABASE_URL` 中的只读角色授予新 schema 的 USAGE 和表 SELECT 权限。连接必须指向同一数据库。
- Google Patents 的检索结果由页面脚本加载，因此专利采集使用专用 Chrome；无需登录，也不访问 PDF 下载入口。天眼查企业查询通过同一浏览器上下文调用公开 JSON 接口。
- 分别启动 `pnpm dev:research`、`pnpm dev`。

统一研究服务仅监听本机 8001，所有接口要求内部 Bearer 令牌。采集协调器通过进程内接口调用 worker，不再监听 8002。Windows 数据库事件循环和浏览器子进程循环分开运行。不要同时启动多个使用同一专用浏览器配置的实例；数据库锁也会阻止第二个 worker。

专用配置默认为用户目录下 `.tech-scout/browser-profile`。其中 `tech-scout-session.json` 包含来源站 Cookie，只保存在本机，不应提交 Git、上传、分享或写入研究数据库。导航内容不属于业务来源；保存的专利材料只包含详情主体，企业数据仅保存业务所需工商字段，不保存电话和邮箱。

## 数据与恢复

- `ingestion.job`：确认后的任务、进度、错误、状态。
- `ingestion.item`：本轮发现记录、页检查点、已完成专利与企业结果。
- `catalog_v2.patent`：公开号唯一，公开日与授权日分开，缺失日期为 null。
- `catalog_v2.company`：统一社会信用代码唯一；名称相似不作为唯一键。
- `catalog_v2.release`：本轮不可变快照，以研究运行 ID 为版本号。

暂停会停止后台浏览器任务。恢复复用已完成条目；失败不会自动生成替代数据。429 尊重退避时间，验证码或解析异常会进入等待。网络错误最多重试三次。任一未完成的详情保留为待恢复状态，当前版本不会静默跳过失败项并发布“完整”结果。

Google Patents 列表与详情中的中国企业申请人分别保留。统一社会信用代码只用于企业事实去重，不能证明专利归属；Agent 映射只存在于本次研究快照，并明确标为推断关联。不能把专利命中等同于产品能力。

模型预算不计网页采集等待时间，采集调用另有六小时上限；重试沿用已有预算。

## 验证

- `pnpm test:research`：Google Patents 网页结构、中国专利/企业过滤、Top 20 权利人、Top 5 候选、Agent 映射校验、100 条中断恢复及研究工作流。
- 在 `services/research/.env` 或进程环境中配置指向**独立测试库**的 `TEST_ACQUISITION_DATABASE_URL` 后运行上述测试，可验证真实数据库唯一性、暂停以及快照不可变性。进程环境优先，不配置时跳过数据库测试。
- `uv run --project services/research pytest services/research/tests/intelligence` 包含空库计划确认门禁测试。
- `pnpm validate` 检查 TypeScript 契约、页面、API 和构建。未配置相应独立数据库的端到端测试会跳过，不能视为已通过。

真实站点验收需单独记录来源访问结果。测试夹具的 100 条通过不代表网站已完成 100 条采集。若来源要求验证，应先处理等待原因，再使用原任务恢复。

## 累计库与旧数据清理

累计库读取事实表，并通过 `record_source` 追溯研究、方向、网页、观察时间。`run_projection` 提供正在采集的事实投影，不含公司—专利关系；完成快照保持不可变。

`browser-v2` 不读取旧研究。停服务并完成迁移后运行 `pnpm reset:research:v2`，显式清空本地研究、采集、目录、快照与检查点数据；账号和登录会话保留。重置脚本拒绝连接非本地主机，且不会删除共享数据根目录或浏览器登录资料。

## 2026-09-09 来源页面验证

未登录状态下已用普通 Chrome 验证 Google Patents 检索、翻页和中文详情页。“固态电池”在 `country=CN`、`language=CHINESE` 下显示超过 100,000 条结果，每页 10 条；结果页可读取中文标题、CN 公开号、申请人、发明人、优先权/申请/授权/公开日期和摘要。详情页可读取摘要、说明书、权利要求、分类号和元数据。该查询仍会出现外国企业的中国专利，因此采集器继续按中文企业申请人本地过滤。

同日验证天眼查企业接口：企业全称和统一社会信用代码均可查询。当前任务抽样的 8 家中国企业全部返回对应候选及信用代码；接入时清理高亮标签、统一中英文括号，并按规范化全称精确匹配。电话和邮箱不进入采集记录。
